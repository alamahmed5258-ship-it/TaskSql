1- الفرق بين DELETE و TRUNCATE
الاتنين بيستخدموا في حذف البيانات من الجدول، لكن في شوية اختلافات بينهم.
DELETE	TRUNCATE
يمكن حذف بيانات محددة أو كل البيانات.	يحذف كل البيانات من الجدول.
يمكن استخدام WHERE.	لا يمكن استخدام WHERE.
أبطأ في الحذف غالبًا.	أسرع في الحذف غالبًا.
يسجل حذف كل صف في الـ Transaction Log.	يستهلك مساحة أقل في الـ Transaction Log.
لا يعيد ضبط الـ Identity.	يعيد ضبط الـ Identity.

مثال على DELETE:
DELETE FROM Employees WHERE ID = 5;


هنا بيتم حذف الموظف اللي رقمه 5 فقط.

مثال على TRUNCATE:
TRUNCATE TABLE Employees;


هنا بيتم حذف كل البيانات الموجودة في الجدول بدون حذف الجدول نفسه.
2- Transaction Log Backup
هو نوع من أنواع النسخ الاحتياطي في SQL Server، بيحفظ سجلات العمليات والتعديلات اللي حصلت داخل قاعدة البيانات، زي الإضافة والحذف والتعديل.

أهميته إنه بيساعدنا نسترجع البيانات في حالة حدوث مشكلة، وكمان ممكن نسترجع قاعدة البيانات لوقت معين قبل حدوث المشكلة.

ويتم استخدامه مع نظام الاسترداد Full أو Bulk-logged.

مثال:
BACKUP LOG CompanyDB
TO DISK = 'D:\Backup\CompanyLog.trn';


الكود ده بيعمل نسخة احتياطية من سجل المعاملات الخاص بقاعدة البيانات.
3- What is a Database Job?
الـ Database Job عبارة عن مهمة بنحددها داخل SQL Server عشان تتنفذ بشكل تلقائي باستخدام SQL Server Agent، من غير ما نحتاج ننفذها بنفسنا كل مرة.

أمثلة على استخدامه:
- عمل نسخة احتياطية كل يوم.
- حذف البيانات القديمة.
- تحديث إحصائيات قاعدة البيانات.
- تنفيذ أوامر SQL في وقت محدد.
مثلاً، ممكن أعمل Job ينفذ Backup لقاعدة البيانات كل يوم الساعة 12 بالليل بشكل تلقائي.

الهدف الأساسي منه هو توفير الوقت وتقليل التدخل اليدوي في المهام المتكررة.
